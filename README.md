# WWDIS Launcher

Соляной лаунчер для Windows, который устанавливает сборку Minecraft Java Edition 1.21.1 с NeoForge 21.1.266 и подключает выбранный профиль к серверу WWDIS `144.31.4.154:25566`.

## Запуск из исходников

1. Установите Node.js 20 или новее.
2. Откройте PowerShell в папке проекта и выполните:

   ```powershell
   npm.cmd install
   npm.cmd start
   ```

   npm 11 блокирует установочные скрипты пакетов, пока они явно не разрешены. В проекте разрешён только скрипт Electron, необходимый для загрузки его исполняемого файла. Если npm всё ещё сообщает, что скрипт заблокирован, выполните:

   ```powershell
   npm.cmd install-scripts approve electron
   npm.cmd rebuild electron
   ```

3. Создайте локальный профиль: введите ник из 3–16 латинских букв, цифр или `_` и нажмите «Создать». Вход Microsoft также остаётся доступен.
4. Настройте выделяемую игре память и нажмите «Прыгнуть в суп». Адрес сервера закреплён в лаунчере.

При первом запуске лаунчер автоматически подготавливает Java 21, скачивает моды по отдельным файлам и конфигурации из публичной папки Google Drive, затем устанавливает NeoForge. Для этого нужен интернет; прогресс загрузки показывает проценты, объём и скорость.

## Сборка установщика

```powershell
npm.cmd run dist
```

Установщик появится в папке `dist`. Подпись и изменение ресурсов `.exe` при сборке отключены: это не требуется для лаунчера и позволяет собрать установщик в Windows без Developer Mode/прав на создание символических ссылок.

## Автоматические обновления

Установленная версия лаунчера при запуске проверяет GitHub Releases, автоматически скачивает новую версию и устанавливает её при закрытии приложения. Сборка из исходников обновления не проверяет.

Workflow `.github/workflows/release.yml` собирает Windows-установщик и публикует релиз при отправке тега версии, например `v1.0.1`. Для первой публикации перенесите файлы проекта в пустой репозиторий `Lustfiner-Slave/Update_Ackadore`, затем из корня проекта выполните:

```powershell
git init
git add .
git commit -m "Prepare launcher auto-updates"
git branch -M main
git remote add origin https://github.com/Lustfiner-Slave/Update_Ackadore.git
git push -u origin main
git tag v1.0.1
git push origin v1.0.1
```

GitHub Actions создаст релиз с установщиком и метаданными обновления. В дальнейшем увеличивайте `version` в `package.json` и `package-lock.json`, отправляйте изменения, а затем публикуйте соответствующий тег `v<version>`.

## Java и файлы игры

Нужные файлы Minecraft 1.21.1 и NeoForge 21.1.266 автоматически загружаются при первом запуске. Если Java 21 не найдена, лаунчер загружает Eclipse Temurin в собственный каталог игры и использует её для установки и запуска.

## Безопасность и данные

Настройки и папка игры хранятся в каталоге данных Electron для текущего пользователя Windows. Токен аккаунта Microsoft сохраняется в зашифрованном виде через Windows `safeStorage`; пароль Microsoft лаунчер не получает и не сохраняет. Локальный профиль использует указанный ник и не выполняет вход или проверку лицензии. Подключение локального профиля возможно только к серверам, настроенным на офлайн-аутентификацию; обычные серверы с обязательной проверкой Microsoft-аккаунта такой профиль не примут.

Адрес сервера WWDIS закреплён: `144.31.4.154:25566`. Лаунчер не позволяет изменить IP или порт.
